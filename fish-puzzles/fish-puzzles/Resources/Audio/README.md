# Audio Assets

Place the following audio files in this directory:

1. **underwater_ambience.m4a** - Gentle underwater bubbling sounds with soft ocean ambience
2. **chest_open.wav** - Magical treasure chest opening sound with sparkles  
3. **tap.wav** - Soft, friendly tap/click sound for UI interactions
4. **menu_theme.m4a** - Upbeat, cheerful menu music loop

The app will run without these files but will log warnings to the console.
